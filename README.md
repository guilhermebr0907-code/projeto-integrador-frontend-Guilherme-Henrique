# Paginas-de-fut
Projeto de desenvolvimento front-end para web.
Página criada para que seja possível acessar de maneira fácil a página de times de futebol pelo Brasil inteiro, onde será possível escolher cada estado e selecionar todos os times desse estado que estão entre as 4 divisões do futebol brasileiro.

Avaliado por: Maria Eduarda Santos

+ Gostei bastante da proposta do site, principalmente por apresentar informações sobre o futebol brasileiro de uma maneira mais interativa e interessante. Achei o código bem organizado e fácil de entender, especialmente pela forma como as seções foram divididas, facilitando a navegação pelo site. Um ponto que chamou minha atenção foi a parte sobre as dívidas dos clubes, pois traz uma informação diferente e complementa bem o conteúdo apresentado.
Também gostei da utilização de imagens para representar as quatro divisões do futebol brasileiro, deixando o site mais visual e atrativo. Percebi que você utilizou tags semânticas, como header, main, section e footer, o que contribui para uma melhor estruturação do código. Como sugestão, acredito que a tabela das dívidas poderia ter um título próprio utilizando a tag caption, facilitando a identificação do conteúdo. Outra melhoria seria adicionar o atributo scope="col" nos cabeçalhos da tabela, contribuindo para a acessibilidade, principalmente para quem utiliza leitores de tela.
Também achei que seria interessante informar a fonte dos dados próxima à tabela, já que os valores das dívidas podem sofrer alterações ao longo do tempo. A parte do cadastro também ficou interessante, principalmente pela utilização de campos obrigatórios e da validação de e-mail, que ajudam no preenchimento correto das informações.

+ No geral, achei que o projeto ficou bem desenvolvido, com uma proposta criativa e uma boa organização. As sugestões são apenas pequenos ajustes que, na minha opinião, poderiam deixar o site ainda mais completo e acessível, caso deseje.
