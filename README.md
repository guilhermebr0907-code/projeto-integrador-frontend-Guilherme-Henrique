# Paginas-de-fut
Projeto de desenvolvimento front-end para web.
Página criada para que seja possível acessar de maneira fácil a página de times de futebol pelo Brasil inteiro, onde será possível escolher cada estado e selecionar todos os times desse estado que estão entre as 4 divisões do futebol brasileiro.
